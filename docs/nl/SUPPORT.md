# Innosend Integration Module - Support

## Support Opties

### Standaard Support

- Email: support@innosend.com
- Reactietijd: 48 uur
- Inbegrepen bij module licentie

### Prioriteit Support

- Email: priority@innosend.com
- Reactietijd: 24 uur
- Beschikbaar als add-on service

## Support Bereik

### Inbegrepen

- Installatiehulp
- Configuratiehulp
- Bug fixes
- API-connectiviteitsproblemen
- Documentatievragen

### Niet Inbegrepen

- Aangepaste ontwikkeling
- Third-party integraties
- Thema wijzigingen
- Prestatie optimalisatie
- Server configuratie

## Problemen Melden

Bij het melden van problemen, graag vermelden:

1. Magento versie
2. PHP versie
3. Module versie
4. Foutmeldingen
5. Stappen om te reproduceren
6. Relevante logbestanden

## Logbestanden

Belangrijke logbestanden:
- `var/log/system.log`
- `var/log/exception.log`
- `var/log/debug.log` (indien ingeschakeld)
